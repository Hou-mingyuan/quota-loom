# 隐私与数据处理

## 本机读取的数据

应用读取用户明确选择的数据目录，或 `$CODEX_HOME` / `~/.codex` 指向的目录。它逐行解析 Claude Code、Codex CLI 或 ChatGPT Codex 的 JSONL 会话记录。

解析过程会在内存中反序列化完整 JSON 行以定位统计字段，但不会把提示词或模型回复正文写入应用数据库。

## 本地保存的数据

SQLite 统计缓存包含：

- 会话和事件标识
- 事件时间和模型名
- 输入、缓存输入与输出 Token 数量
- 源文件路径、大小、修改时间和解析字节偏移
- 模型价格与用户设置的倍率

配置目录还会保存所选数据目录和悬浮窗位置。所有这些文件都位于当前用户的操作系统应用数据或配置目录中。

源文件路径和会话标识可能间接包含用户名或项目名称，因此应用数据库仍应视为私人数据。

## 网络请求和本地 Codex 进程

应用启动时以及用户手动刷新价格时，会向以下地址发送 HTTPS GET 请求：

```text
https://models.dev/api.json
```

该请求用于取得公开的模型名称和价格，不包含提示词、回复、会话标识、Token 统计或本地路径。

为显示 ChatGPT Codex 账户的每周额度，应用还会按需启动：

```text
codex app-server --stdio
```

应用通过本地标准输入/输出请求 `account/read` 和 `account/rateLimits/read`，只保留账户是否为 ChatGPT 类型、额度百分比和重置时间，并在内存中缓存最多 60 秒。这些值不会写入 SQLite。

Codex CLI 可能使用其现有登录状态连接 OpenAI 服务。登录凭据由 Codex CLI 管理；本应用不会读取、复制或保存凭据。账户限额请求不包含本地会话正文，但会遵循 Codex CLI 自身的网络和隐私行为。

除此之外，项目没有遥测、崩溃上报、广告或行为分析服务。

## 删除数据

界面中的“重建缓存”会清除并重新生成统计缓存，但不会修改原始会话文件。要完全删除应用保存的数据，请退出应用后删除操作系统为 QuotaLoom 分配的应用数据和配置目录。

## 提交问题

不要公开上传：

- 原始会话 JSONL
- `usage.sqlite3` 及其 WAL/SHM 文件
- `codex-home.json`
- 包含用户名、项目名或绝对路径的截图
- API Token、Cookie 或其他凭据

复现解析问题时，请使用最小化的虚假数据，并替换所有会话标识、路径、时间和文本内容。
